# 当前状态

## 目标与边界

固定语义入口只有 `漫画`、`漫书` 两个根查询词。执行入口随后在线发现候选域名，读取站点公开首页中的
表单、导航和分页链接，生成站内搜索模板及种子页面，再审计公开详情页、章节页和
图片信号，最终生成规则索引与目录。数量预算、超时和语言是运行控制参数，不参与
搜索语义。

流程只处理无需登录的公开 HTTP/HTTPS 页面，不绕过登录、付费、验证码、DRM 或
反爬机制。“全网”表示在搜索服务可见、网络可达且通过公开页面审计的开放集合，
不是对互联网所有站点作绝对覆盖承诺。

## 唯一入口

```powershell
python scripts/run_full_pipeline.py --language zh-Hans
```

可通过 `--resume-from` 从中断阶段继续。完整阶段为：

```text
漫画 + 漫书 -> 参数自举 -> 域名发现 -> 站点参数发现 -> 关键词发现
     -> 规则审计/生成/清洗 -> 目录生成 -> 发布质量闸门
```

## 质量策略

- 不复制条目或跨分类伪造数量。
- 每个分类至少 200 条；默认不设最大值，只有显式配置 `PIPELINE_MAX_CATEGORY_COUNT` 才截断。
- 每条发布目录必须在同一个来源中同时具有有效书名详情链接和封面链接。
- 每条目录分类必须带 `categoryEvidence`，来源只能是公开分类页、URL、标签或详情元数据；不按数量轮询填类。
- 目录标题拒绝样式表、脚本、资源文件、章节页及导航噪声。
- 通用 `url-only` 规则允许空主页；普通站点规则必须有 HTTP(S) 主页。
- 发布前校验两个根查询、规则 ID、URL、目录去重、来源及域名生命周期；发现域名必须进入已覆盖、明确拒绝或待判定状态，只有可生成域名要求规则全覆盖。
- Actions 汇总展示分类数量、链接完整率、规则域名覆盖率和参数来源，失败结果同样可见。
- 失败运行仍上传目录缺口和域名闭环账本，区分无候选、审计失败、登录付费与清洗淘汰。
- 未达到 `--min-rules` 或 `--per-category` 时流程失败且不发布。
